# 鲨牙危机

适合聚会轮流玩的竖屏触控小游戏。打开 `index.html` 即可试玩，无需安装依赖。

## 玩法

1. 点击「开始游戏」。
2. 每人轮流点一颗还没按过的牙齿；按过的安全牙会缩下去。
3. 每局随机指定 18 颗牙中的一颗为机关牙。点到它时，鲨鱼会咬合并显示触发的玩家序号。
4. 点击「重新开局」或「再来一局」重新随机开始。

每局还会随机展示一套鲨鱼主题：深海巡游、珊瑚泡泡、薄荷汽水、星夜幻鲨、落日柠鲨。连续两局不会出现同一套主题。开场画面显示的主题会保留到第一次游戏开始。

右上角可开关音效。支持触屏、鼠标和键盘操作；设备支持时会有轻微震动。

## 项目文件

- `index.html`：游戏界面与矢量鲨鱼插画
- `style.css`：竖屏布局、牙齿形状与动画
- `game.js`：随机机关、轮流计数、反馈与重开逻辑
- `dist/鲨牙危机-游戏图标-v2.png`：推荐使用的 1:1 二维卡通游戏图标，用于平台后台上传；不在小工具离线 ZIP 内

## 用在小红书

若使用小红书「小工具」离线 H5 上传入口，请选 `dist/鲨牙危机-小红书小工具.zip`。该包只有根目录 `index.html`、`style.css`、`game.js`，不需要部署业务域名。上传前请在小红书的小工具模拟器及真机容器检查画面、点击、音效与震动。

若使用小红书小程序的 `web-view`，可选 `dist/鲨牙危机-小红书接入包.zip`。它包含 H5 文件与页面模板，具体步骤见包内的「小红书接入说明.md」；该路线需要 HTTPS 业务域名、小程序 ID 和相应审核，**不能作为「小工具」ZIP 直接上传**。官方文档提供了[小游戏配置说明](https://miniapp.xiaohongshu.com/doc/DC519814)和[业务域名与 web-view 说明](https://miniapp.xiaohongshu.com/doc/DC508424)。

`dist/鲨牙危机-H5站点.zip` 用于普通静态网站部署，其中包含说明文档，也不属于「小工具」ZIP。
