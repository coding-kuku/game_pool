# 鲨牙危机 · 小红书接入包

本说明适用于小程序 `web-view` 接入包。若在小红书「小工具」入口上传离线 H5，请使用独立的 `dist/鲨牙危机-小红书小工具.zip`：解压后根目录直接是 `index.html`、`style.css`、`game.js`，无需配置业务域名。

## 包内文件

- `h5/`：可直接部署的静态游戏页面。三个文件须放在同一目录；部署后访问 `index.html`。
- `xhs-miniapp-template/`：小红书小程序 `web-view` 页面模板，以及接入步骤。

## 已完成的手机适配检查

使用 Chrome 手机视口与触摸模拟检查了 390×844、375×667、320×568、375×600、320×500。五种尺寸均无横向溢出，页面底部完整可见；每种尺寸的 18 颗牙点击中心均能命中对应牙齿，触摸后正常进入下一位玩家。

这些是浏览器模拟结果。小红书开发者工具和 iOS、Android 真机的最终显示仍需用实际小程序核对。

## 接入顺序

1. 将 `h5/` 中的三个文件部署到自己的 HTTPS 业务域名。
2. 在小红书开放平台创建小程序、确认账号可用类目，并配置及验证业务域名。
3. 在小红书开发者工具创建项目，将模板文件复制进去，把 `pages/index/index.js` 中的 `gameUrl` 改成已部署的 H5 地址。
4. 在开发者工具与真机上预览，再根据后台要求提交审核。

本包已可独立试玩和部署 H5；小程序模板需要你的域名与小程序 ID 才能连到游戏。小红书原生小游戏使用另一套配置和运行环境，不能将本 H5 ZIP 直接作为原生小游戏包上传。

官方参考：[小程序介绍与接入流程](https://miniapp.xiaohongshu.com/doc/DC137160)、[web-view 业务域名](https://miniapp.xiaohongshu.com/doc/DC508424)、[小游戏配置](https://miniapp.xiaohongshu.com/doc/DC519814)。
