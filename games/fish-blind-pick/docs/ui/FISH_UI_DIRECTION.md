# 盲选小鱼：UI 风格提案 v1

## 项目与交付边界

这是「盲选小鱼」独立项目的视觉方向稿。可玩的实现位于项目根目录 `index.html`；本稿用于说明造型、配色和交互意图。

仓库内 `.codex/minitool-zip-builder/SKILL.md` 规定的目标是小红书「小工具」离线 H5 ZIP：`index.html` 在 ZIP 根目录；资源在包内、用相对路径；JavaScript 用外链经典脚本，不能用内联脚本、行内事件或 module；直接交付的 JS 以 ES2017 / Chrome 61 为基线；竖屏自适应并处理安全区；ZIP 不超过 10 MiB，建议小于 2 MiB。

[小红书官方小工具容器能力清单](https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8323q4m0uaga06277180ac7t8006ptl0e12ek1g)也明确：小工具是纯 Web、离线运行；支持标准 HTML/CSS/JS、Canvas 2D、SVG；资源必须在包内，脚本只能从包内文件加载，禁止网络请求、内联脚本和行内事件。`index.html` 根目录、10 MiB、Chrome 61 等更具体的交付要求来自**项目 skill**。开放平台[小游戏配置](https://miniapp.xiaohongshu.com/doc/DC519814)使用 `game.json`，是另一套交付形态，不能混用。

## 风格主张：海底糖果玩具盒

参考《小鳄鱼爱洗澡》《割绳子》的广义视觉语言：圆润轮廓、厚描边、鲜明但柔和的配色、表情化小角色、像玩具一样的按压反馈。鱼的造型、图标、排版和场景都重新设计，不使用现有游戏的角色或素材。

- **情绪**：轻松、调皮、适合朋友围着一台手机喊结果。酒桌是使用场景，画面仍以鱼和比分为主，不画酒瓶或强制饮酒惩罚。
- **舞台**：奶油色沙底 + 浅青色水池；半透明气泡、水草只做边角装饰，中间留给 8 个鱼头。
- **造型**：鱼头占同尺寸卡片的中心，统一大小和轮廓。颜色与表情可变化，但必须与隐藏节数独立随机，不能泄露长度。
- **线条**：深海蓝描边约 3–5 px，外轮廓厚、内部细；阴影短而实，避免复杂渐变和发光。
- **质感**：软糖按钮、浮起的贝壳牌、泡泡爆开的反馈。优先用轻量 SVG / CSS 制作，避免大图集。

## 颜色与排版

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 深海描边 / 正文 | `#244B5B` | 文字与卡片轮廓 |
| 海水背景 | `#8EDDD8` | 主场景 |
| 沙色底 | `#FFF2D2` | 面板、结果页 |
| 蓝队 | `#4E8ED8` | 选中牌与计分 |
| 珊瑚队 | `#F47269` | 选中牌与计分 |
| 主按钮黄 | `#FFD365` | 揭晓 / 再玩一局 |
| 草绿点缀 | `#A9D976` | 尾鳍、气泡装饰 |

标题使用圆润粗体的系统中文字体栈，24–30 px；主数字 34–48 px；正文 14–16 px；辅助文字不小于 12 px。高信息区用实色底，不把文字压在复杂插画上。颜色之外始终用「蓝队 / 珊瑚队」文字标识归属。

## 三个核心画面

1. **轮流盲选**：顶栏明确「轮到蓝队」和双方 `已选 x/4`。中间是 2 列 × 4 行鱼头卡，8 张卡同尺寸、同点击面积。点击后浮出对应队伍的小旗与卡框；该鱼头不可再次选。选择阶段不显示身体、长度数字、尾巴或任何暗示。
2. **逐条揭晓**：8 条全部选完才进入揭晓。玩家每次点开一张尚未揭晓的鱼牌，鱼身一节一节弹出，最后显示本条 `+N 节`，同时更新该队累计分。底部有「继续揭晓」按钮，返回剩余鱼牌；动画可点按跳过。
3. **结果**：分别列出 4 条鱼的节数和总节数，大数字并排比较；胜方有小鱼跃起与轻量纸屑反馈，平局用双鱼击鳍。主要按钮是「再玩一局」。不把“喝几杯”设为游戏规则或结算条件。

## 动效与触摸

- 选鱼：按下后有短促的下压回弹。
- 揭鱼：节数是事实信息，动画让已经确定的身体节数顺次展开；玩家可以立即继续。
- 计分：揭开后更新对应队伍的累计分牌。平局也给明确结果。
- 主操作目标至少约 44 × 44 px；360–430 px 宽竖屏不横向滚动，底部按钮避开安全区。本版无声音，反馈均可从画面理解。

## 当前实现口径

- 每条鱼独立等概率抽取 1–6 节；允许同长。
- 蓝队先选，双方轮流直到各得 4 条。
- 揭晓阶段可任意顺序点开尚未揭晓的鱼。
