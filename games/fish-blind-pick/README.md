# 盲选小鱼

两人同屏轮流选鱼的轻量聚会游戏。当前版本是可直接打开的离线 H5，按小红书「小工具」的包内资源约束制作。

## 试玩

双击项目根目录的 `index.html`，或用本地静态服务器打开项目根目录。无需安装依赖，也不需要网络。

选鱼、揭晓和结算有轻量音效；右上角的「有声／静音」按钮可随时切换，设置会保存在本机。音效由浏览器即时生成，离线包不需要额外音频文件。

## 规则

1. 场上有 8 个鱼头。鱼身长度在选择时隐藏。
2. 蓝队先手，两人轮流选鱼，每人各得 4 条。
3. 8 条选完后，任意顺序逐条点开，查看每条鱼的身体节数。
4. 各自 4 条鱼的节数相加，总数多的一方获胜；相同则平局。

当前每条鱼独立等概率抽取 **1–6 节**。鱼头颜色和位置与长度无关。刷新页面后，本局进度会尝试从本地存储恢复；存储不可用时仍可正常新开一局。

## 文件

- `index.html`、`styles.css`、`app.js`、`src/game.js`：小游戏运行文件。
- `tests/game.test.js`：轮流选鱼、揭晓、计分和平局等逻辑测试。
- `docs/ui/FISH_UI_DIRECTION.md`：视觉、画面和交互方向。
- `docs/ui/fish-ui-concept.svg` / `.png`：设计概念图。
- `docs/ui/live-*.png`：浏览器中的实际画面预览。
- `release/fish-blind-pick.zip`：离线小工具运行包；ZIP 根目录直接包含 `index.html`。
